# TVXO

TVXO is a Live TV and streaming app for Google TV and Android TV (package `com.tvxo.tv`).
Live TV is added with an **Xtream Codes login** (server URL, username, password).

- Build, signing, releases and updates: see [TVXO_BUILD_GUIDE.md](TVXO_BUILD_GUIDE.md)
- Remote control shortcuts: [CONTROLS.md](CONTROLS.md)
